# Space Invaders Game 🎮🚀

This is a simple **Space Invaders** game built using **Java Swing**. The player controls a spaceship that can shoot bullets to destroy incoming alien ships. The aliens also shoot back, and the goal is to survive and score as many points as possible.

---

## 🧩 Features

- Classic arcade-style gameplay
- Player-controlled spaceship movement and shooting
- Alien enemies that shoot bullets
- Score tracking
- Game Over screen with restart functionality
- Smooth graphics with custom alien designs

---

## 🛠️ Technologies Used

- Java 8+
- Java Swing for GUI
- Object-oriented design
